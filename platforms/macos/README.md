# ClarityIME — macOS (InputMethodKit)

ClarityIME is an **integrated input method** — **voice clarify inside IME** via InputMethodKit, not a floating overlay, not a stack on 搜狗/讯飞, not Typeless. The IMK shell talks to the Python core at `http://127.0.0.1:17800`.

**We do NOT integrate Typeless or external ASR apps — ClarityIME includes its own ASR + clarify pipeline.**

Differentiation: **audience-targeted clarification**, not style polish.

## What gets installed

| Piece | Role |
|-------|------|
| **LaunchAgent** `com.clarityime.serve` | Runs `clarityime serve` at login |
| **ClarityIME.app** | InputMethodKit app in `~/Library/Input Methods/` |
| **`CLARITYIME_ROOT`** | Points Xcode / shell to the repo for Python capture |

---

## Step 1 — Install Python core (no Xcode yet)

In Terminal:

```bash
cd code-ClarityIME/platforms/macos
chmod +x install.sh build.sh
./install.sh
```

This creates `.venv`, installs `clarityime`, writes `CLARITYIME_ROOT` to `~/.zprofile`, and installs the LaunchAgent from `LaunchAgents/com.clarityime.serve.plist.template`.

Check core is up: open **Safari** → `http://127.0.0.1:17800/v1/health` (should return JSON).

---

## Step 2 — Build the IMK app

**Requirements:** macOS 13+, Xcode 15+, [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

### Option A — script (recommended)

```bash
cd code-ClarityIME/platforms/macos
./build.sh
# → dist/ClarityIME.app
```

Run unit tests while building:

```bash
RUN_TESTS=1 ./build.sh
```

### Option B — Xcode GUI

1. `cd platforms/macos && xcodegen generate`
2. Open **`ClarityIME.xcodeproj`** in Xcode
3. Select target **ClarityIME** → **Signing & Capabilities** → choose your **Apple ID** team (Personal Team is fine for local use)
4. **Product → Build** (⌘B) or **Product → Archive** for release

Project layout:

```
platforms/macos/
  project.yml              # xcodegen spec → ClarityIME.xcodeproj
  Package.swift            # notes only; IMK builds via Xcode
  build.sh
  install.sh
  ClarityIME/              # IMK app (main.swift, Info.plist, entitlements)
  ClarityCore/             # shared offline clarify logic
  ClarityIMETests/         # XCTest
  LaunchAgents/            # serve plist template
```

## Step 3 — Install IMK app + enable in System Settings

```bash
./install.sh          # copies dist/ClarityIME.app if built
```

Or manually: drag **`dist/ClarityIME.app`** to **`~/Library/Input Methods/`** (Finder → Go → Go to Folder… → paste that path).

### Enable the input source (UI — not terminal-only)

1. **Log out and log back in** (or restart) so macOS registers the new input method.
2. Open **System Settings** (Apple menu → System Settings).
3. Go to **Keyboard** → **Text Input** (or **Input Sources** on older macOS) → **Edit…**.
4. Click **+**, choose **ClarityIME** (under Chinese or “Others” depending on OS version) → **Add**.
5. In the menu bar input menu, switch to **ClarityIME** when typing in any app.

### Microphone (for voice clarify)

When you first use **🎤 Voice clarify**, macOS may prompt for microphone access for **Terminal** / **Python** (capture runs via `python -m clarityime.main capture`). Allow it under:

**System Settings → Privacy & Security → Microphone** → enable **Terminal** (or **Python**) if needed.

---

## Step 4 — Use

1. Focus any text field; select **ClarityIME** from the input menu.
2. Open the IMK **menu** (input menu or controller menu) → **🎤 Voice clarify**.
3. Speak (~5 s) → candidate picker alert → **Apply** → text inserts at the caret.
4. Switch **Mode** (`default` / `ai` / `contact`) from the same menu.

If the core is down, offline rules in `ClarityCore` still return a single candidate.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| ClarityIME not in Input Sources list | Confirm app is in `~/Library/Input Methods/`, then log out/in |
| Build signing errors | Set team in Xcode or `CODE_SIGN_IDENTITY="Apple Development: …" ./build.sh` |
| Core not running | `launchctl print gui/$(id -u)/com.clarityime.serve` or re-run `./install.sh` |
| Empty capture | Check `CLARITYIME_ROOT`, mic permission, `clarityime serve` logs at `$CLARITYIME_ROOT/.clarityime-serve.log` |
