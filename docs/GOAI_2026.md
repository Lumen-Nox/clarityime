# GOAI 2026 — Boundless Agents, Topic 4 (AI + Education)

This repository is the runnable companion to the ClarityIME preliminary
design. A reviewer can check claims against code instead of slides.

Author: **Lumen**. Track page: [Boundless Agents](https://www.goaihz.com/en/tracks?track=apps).

| Handbook / topic need | Where it is |
|---|---|
| Education use | Same sentence, lower comprehension cost for a *named listener* (classmate, teacher, younger sibling). Not a tone polisher. |
| Audience model | Tag registry: 17 families. Personality never implies domain knowledge. `edu` / `topic` grant study-circle words; `topic_memes` grants `internet`; age / gender / place never do. |
| Cross-circle teaching | `clarify/analogy.py` — audited 1:1 role mappings mixed into daily output (`守椅（就像架点）`). No LLM. No owned analog → plain T1 jargon. |
| Affect-first teaching | Fi/Fe listeners see stance/feeling clauses before logistics (`A8a`). Same propositions. Affect words such as 委屈 / 害怕 are their own detail units. |
| Consent before a new audience | DEFAULT-mode ratings never silently create a contact. The UI gets `auto_name_preview` (`对象 N`); yes/no is required. |
| No new content | Invariants in `tests/test_comprehension.py`. Hedges, questions, polarity stay. |
| Determinism | `tests/test_determinism.py` AST-scans `clarify/` for `random` / HTTP / LLM. |
| Privacy | Loopback API, fragment-only share links, consent defaults off. |
| Openness | Apache-2.0. Core extra is `rich` only. |

Public preset names: `analytical`, `warm_flow`, `fast_scan`, `narrative`.

## Reproduce

```bash
pip install -e .
python -m unittest discover tests -v
clarityime demo
clarityime clarify "监管者一直守椅" --listener analytical
```

`clarityime demo` prints two classmates on the same sentence: no game/meme
tags → plain gloss; `game_valorant` + `topic_memes` → `守椅（就像架点）`
and the speaker's `破防` kept. A listener with no owned analog still gets
the plain-language gloss, not a comparison.

## Versioning (zip vs GitHub)

This repository on `main` is the **live copy** and is updated continuously.
